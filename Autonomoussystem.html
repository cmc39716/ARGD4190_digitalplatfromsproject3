HOW IT WORKS

Hundreds of particles drift across the canvas and leave thin trails. A smooth noise() field decides which way each particle turns, so the trails flow like currents. Each time you click, the noise field gets a new seed, a new scale and a new amount of swirl, so every drawing has a different flow.

random() adds the jumpy decisions: which palette color a particle gets (mostly black, some red, a little gray), how thick and how transparent its line is, how long it lives, and when it stops to stamp a nested quarter-arc. Those arcs come from my optical pattern piece, so the two pages share a visual language. The drawing builds up for a few seconds and then freezes.

Rules: particles array and loops, mousePressed() starts a new drawing, keyPressed() saves it with saveCanvas(). The flow-field technique is a common generative art approach; this code is my own.
